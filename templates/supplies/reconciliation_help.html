余额核对与受控重建

日常业务不依赖重建；重建仅用于不可变流水与缓存发生异常差异后的维护窗口处理。

返回 Dashboard

1. 只读核对

由管理员在应用服务器执行，命令不会写入数据：

python manage.py reconcile_supply_balances --company {{ company.code }}
python manage.py reconcile_supply_custodies --company {{ company.code }}

2. dry-run

发现差异后先填写真实操作人和原因；不加 --confirm 只输出差异：

python manage.py rebuild_supply_balances --company {{ company.code }} --actor <用户名> --reason "<原因>"
python manage.py rebuild_supply_custodies --company {{ company.code }} --actor <用户名> --reason "<原因>"

3. 维护窗口确认

核对 dry-run 差异、暂停相关业务并完成审批后，追加 --confirm。系统按稳定顺序锁定仓库/余额或保管记录，拒绝活动盘点，事务化更新缓存、再次核对并写审计。历史库存流水、保管流水、单据、来源链和单位成本快照均不会修改或删除。

不要直接修改数据库、删除流水、删除保管记录或改写历史迁移。
