# EAM-Lite 0.2.2-rc.1 试用指南

## 进入系统

仅在本机使用时，双击“启动开发环境.cmd”，浏览器访问 `http://127.0.0.1:8766`。需要其他电脑或手机一起试用时，使用“启动开发环境-局域网扫码测试.cmd”，按启动窗口显示的局域网地址访问。使用分配的业务账号登录。

设备、仓库和财务按各自岗位权限办理业务。页面顶部显示当前环境，进入后先核对公司名称。

## 资产建档

1. 在“逐件资产 → 全部逐件资产”新增资产，或下载当前 Excel 模板后批量导入。
2. 核对实物分类、首次管理属性、部门、责任人和具体位置。资料未齐时保存为草稿。
3. 资料齐备后办理建档，取得正式编号。照片可以后补；财务金额与折旧另行确认。
4. 打印并贴好标签后，在 EAM-Lite 顶部打开“扫码资产”，用页面相机、二维码照片或扫码枪识别并确认；单独用手机系统相机不会直接打开资产页面。适用电子台账或替代标识的资产，按对应入口确认。

每条逐件资产代表一件管理对象；按数量管理的物品从“数量物品”办理。低值耐用品可按逐件或按数量管理，按实际追踪需要选择。入口区别及自动编号示例见 [物品管理方式与档案编号](Item-Management-and-Numbering.md)。

在“基础资料与设置 → 位置”按实际地点填写名称和上级位置，编号可留空自动生成。资产选择没有下级的启用位置；新增位置不需要选择位置类型。

新增物品、仓库、分类、部门、员工、位置等档案时，编号留空可自动生成，也可手工填写。已有档案编辑时保留原编号；外部凭据号码及 Excel 导入匹配编码按实际资料填写。

## 批量补资料与建档

在资产台账进入“批量建档”。同一浏览器会话中可跨页勾选，最多选择 200 件；“清除选择”清空当前选择。

需要统一补资料时，展开“批量补充草稿资料”，选择部门、责任人或位置，并填写补充说明。留空的字段保持原值；改变部门时同时核对责任人。

先预览各件资产的修改前后内容，再确认保存。预览后任一件资料发生变化、目标资料不可用或权限不符，本批不保存，重新核对后办理。重复提交同一个已完成请求不会重复修改。

补充后仍为草稿。点击“核对所选资产”，检查逐件结果，再确认建档。未通过建档核对的记录保留为草稿。已经正式建档的资产，通过调拨等相应业务入口变更责任和位置。

## 财务待办

在“待确认折旧”按资产编号、名称、部门或资料状态查找资产。列表提示已保存基础资料中的缺项；进入详情核对会计认定、原值及适用的折旧设置后办理确认。

首次管理属性与会计认定分别保存。财务认定改变时，原编号及二维码保持不变。

## 查询与导出

- 创建日期：首次保存草稿的日期。
- 正式建档日期：建立正式编号并完成建档的日期；尚未正式建档的草稿不在此日期范围内。
- 台账筛选后，通过“报表与导出”核对范围并生成 Excel。
- 查询历史时点的资产状态或期间财务数据，从报表中心选择对应日期和口径。

## 日常变动与更正

调拨、借还、盘点、保养、清退和处置从相应业务入口办理。操作前核对资产编号、实际业务日期、责任人和依据。

误登记时使用对应撤销或冲销入口，保留原记录和更正原因。租入归还与来源登记的操作见 [批量建档与登记更正](Asset-Registration-Corrections.md)。

## 数据保管

管理员在重要录入和版本更新前保存数据库及附件备份，并将备份保存在独立设备。恢复及迁移电脑的方法见 [本机使用说明](../README-本机使用版.md)。
