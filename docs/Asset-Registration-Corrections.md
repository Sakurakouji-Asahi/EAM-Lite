# 批量建档与登记更正

## 批量建档

在资产台账点击“批量建档”，或在已确认的 Excel 资产导入批次中点击“核对本批资产并批量建档”。

1. 勾选待建档草稿，点击“核对所选资产”。每页显示 100 件；同一浏览器会话可跨页选择，每批最多 200 件。需要统一补充部门、责任人或位置时，先展开“批量补充草稿资料”并预览变更。
2. 核对资产名称、分类、首次管理属性、部门、责任人和位置。缺失资料会按资产列出具体字段，可进入详情补充。
3. 点击“确认建档”。仅办理已通过核对的资产；预览后资料发生变化的记录需要重新核对。
4. 查看逐件办理结果。成功的记录显示正式编号，未完成的记录保留原草稿。

核对预览不占用正式编号。重复提交同一确认请求不会重复建档或重复发号；不同请求也不能为已建档资产再次发号。财务草稿、原值和折旧仍按独立财务流程确认。

## 租入或受托资产归还

在 LS 资产详情点击“租入受托归还”，填写实际归还日期、接收方、合同或受托依据、归还验收依据和原因。

实际归还日期用于历史资产报表，录入时间单独保留。归还日期不能早于最近一次有效业务变动，也不能与后续有效保养记录冲突。独立组件须先分别处理。

实物归还会结束本公司的管理，并终止仍启用或暂停的保养计划。原编号、二维码和保养历史继续保留。涉及已确认固定资产财务或折旧历史时，先完成既有财务处置，再补登记归还依据。

## 更正误登记

在资产详情的“归还登记与更正历史”或“拆分与合并来源”中，找到原记录并点击“撤销误登记”。核对原资料，填写撤销原因与依据，确认后重新登记正确资料。

- 撤销来源登记后，原关系不再作为有效来源关系参与查询和循环校验，原记录及撤销依据仍可查看。
- 撤销实物归还会恢复归还前状态，以及该次归还终止的保养计划。归还后已发生其他业务变动、关联计划已变化或主资产已结束管理时，需要先核对相关记录。
- 对已经完成财务处置的补充归还记录，撤销只影响归还依据，不撤销财务处置或改变金额。
- 撤销的归还及其撤销记录保留在操作历史中，不再用于有效历史资产状态的统计。

权限沿用现有资产资料维护范围。来源撤销同时检查来源资产和目标资产的权限。

## 状态显示

电子台账、替代标识和实物贴标分别显示其确认方式。已归还资产在详情、台账和导出中显示“已归还”；历史变动保留归还及撤销的业务名称。
