# 月度折旧期间录入

折旧批次试算和月度工作量录入，开始日填写当月1日，结束日填写同月最后一天，结束当天计入本期。例如2026年9月填写2026-09-01至2026-09-30；2028年2月填写2028-02-01至2028-02-29。

页面默认显示当前月的月初和月末。填写非整月或跨月日期时，在日期字段旁提示需要的日期。折旧批次列表及详情按相同的月末日期显示，金额为零时正常显示零。

点击“生成试算”只生成待核对批次；核对明细后，仍需另行确认过账。同一次表单重复提交使用相同请求标识，不重复生成批次。

开发说明：表单保留用户填写的包含式截止日，提交服务时统一转换为下一日。原有服务、数据库、折旧计划和分录继续使用左闭右开期间，不调整计算公式或历史记录，无数据库迁移。
