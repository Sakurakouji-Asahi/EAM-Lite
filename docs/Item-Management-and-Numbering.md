# 物品管理方式与档案编号

## 选择登记入口

先按是否需要识别每一件物品选择管理方式，再由财务确认会计认定。

| 入口 | 管理方式 | 适用需要 |
|---|---|---|
| 逐件资产 → 全部逐件资产 | 每件独立编号、登记状态和责任关系 | 需要跟踪具体哪一件，或需要独立二维码、序列号、维修记录 |
| 逐件资产 → 低值耐用品（逐件） | 全部逐件资产中的低值耐用品子集 | 按 LV 管理属性登记的工具、家具等逐件对象 |
| 数量物品 → 低值耐用品（按数量） | 同种物品共用档案，登记库存和领用后的保管数量 | 需要知道某人或部门持有多少件，并办理归还、转交 |
| 数量物品 → 低值易耗品 | 同种物品共用档案，登记库存和领退数量 | 领用后按消耗管理，不形成持续的耐用品保管余额 |

同一件实物选择一种管理方式，避免在两个入口重复登记。物品名称本身不决定管理方式；相同品名也可能因实际追踪要求不同而采用不同方式。

“全部逐件资产”包括逐件低值耐用品。财务认定为固定资产、受控非固定资产或其他类别，是另一项财务信息；首次 FA/LV 管理属性不代替财务认定，后续财务认定改变不改资产编号及二维码。

## 自动编号与手工编号

新增以下档案时，编号留空即可在保存后自动生成；也可以填写已有内部编号。系统按原有规则规范化全角字符、去除首尾空格，并忽略大小写检查重复。

| 档案 | 自动编号示例 |
|---|---|
| 公司 | CO000001 |
| 部门 | 顶级 DP000001，下级 DP000001-01 |
| 员工 | EMP000001 |
| 位置 | 顶级 LOC000001，下级 LOC000001-01 |
| 实物一级分类 | 01—99 中尚未占用的两位数字 |
| 实物下级分类 | 01-01；再下一级可为 01-01-01 |
| 固定资产会计类别 | FAC000001 |
| 数量物品分类 | 顶级 SC000001，下级 SC000001-01 |
| 仓库 | WH000001 |
| 低值耐用品（按数量） | LVD000001 |
| 低值易耗品 | LVC000001 |

顶级档案的普通自动编号按公司、档案类型及前缀，在当前已有六位流水编号之后递增；停用档案也参与判重。部门、位置和两类分类选择上级后，自动编号沿用上级编码，再加两位下级序号。每一级都沿用完整的上级编码。一级实物分类从 01 开始选择空闲编码，保持现有资产编号中两位大类的格式。

编号在保存成功后显示，打开页面或校验未通过不会占号。编辑已有档案不会自动换号，编号不能清空；调整上级也不会自动改写既有编号或下级历史。已有历史的物品档案继续遵守原有编号冻结规则。

逐件资产继续使用现有统一资产编号规则，适用于 FA、LV 等管理属性。入库、领用、调拨及盘点等原有业务单号继续由系统生成。

设备序列号、出厂编号、合同号、历史编号及外部参考号应按真实资料填写。Excel 导入中的编码仍用于匹配资料，须按导入模板填写。
