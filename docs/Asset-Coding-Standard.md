## 已确认的业务口径

用户先要求资产建档与财务确认分开、照片可后补，随后确认：FA/LV 等表示首次建档的管理属性；最终财务认定可以不同，财务确认不改变已有编号或二维码。用户又明确选择“只做编号与来源追溯，财务另行处理”，所以拆分、合并不自动分配或迁移原值、累计折旧。

编码年份不决定折旧起算日期。后续财务根据实际资料独立确认会计处理、日期和折旧设置。明确错码的技术更正仍使用原有管理员受控流程，保留新旧编号和二维码版本；这与普通财务认定变更不同。

## 编码结构

`AA-CC-YYYY-NNNNNN-SS`，例如 `FA-04-2026-000123-00`。

| 段位 | 当前规则 |
|---|---|
| AA | FA 固定资产实物管理、LV 逐件低值耐用品、IA 无形资产、LS 租入或受托资产、OT 其他受控资产 |
| CC | 一级实物分类的两位数字编码；默认提供 01—09 和 99，后续可按实际需要维护其他两位类别码 |
| YYYY | 优先使用明确填写的取得年份及依据；否则使用购置日期年份，日期也未填写时使用纳入管理年份并记录来源 |
| NNNNNN | 每个公司、管理属性、类别码、取得年份单独计数，从 000001 起，最大 999999；规则版本更换继续同一号码池 |
| SS | 主资产 00；组件共用主资产前四段，按 01—99 依次分配，历史子项号保留且不复用 |

组件自己的购置日期可以晚于主资产，编码年份仍沿用主资产。其独立实际日期和财务设置分别保存。序号由后台事务分配，预览不会占号；保存时若有其他人先建档，以最终分配结果为准。

默认实物大类为：01 房屋及建筑物、02 机器设备、03 运输设备、04 电子及信息设备、05 办公家具、06 仪器仪表、07 工器具、08 安防消防设备、09 文化及陈列资产、99 其他。这些属于实物分类，财务会计类别另行维护。库存物品编码继续沿用物品档案或 ERP 的管理体系，不与资产标签号混用。

## 操作方式

1. 管理员从“编码规则 → 采用统一编码规则”建立规则，可同时补充文档中的 10 个实物大类。现有同码分类存在冲突时会提示核对，不会覆盖原分类。
2. 实物基础资料、编码和用户权限就绪后即可完成初始化。折旧政策与财务参数显示为可后补，缺少它们不再阻止先建档；财务确认时仍校验实际所需资料和政策。
3. 新增资产选择首次管理属性与实物分类，可填写取得年份及依据。电子及信息设备需填写序列号，电子许可可填写许可标识；车牌、车架、校准编号另有字段。
4. 从主资产详情选择“新增组件”，系统沿用其管理属性、编码类别、年份和流水，自动填写责任资料，生成独立子项号与二维码。
5. IA 可使用“确认电子台账”，无需打印实物标签。其他实物不便贴标时可填写替代标识及核对依据。两种方式均保留确认人、时间和幂等记录，不伪造打印批次。
6. “组合成员”按完整清单版本记录成员、数量、单位和说明，原清单持续保留。一条资产记录仍代表一个管理对象，成员数量不会自动生成库存流水或调整资产金额。
7. 在目标资产上“登记拆并来源”，保存来源、目标及当时编号，支持双向查询并拒绝循环。只完成来源登记，不自动停用原资产或转移财务金额；这些后续动作由对应流程处理。
8. LS 的归还记录包含实际日期、接收方、合同或受托依据和验收证据。尚无已确认固定资产财务或折旧历史时，可结束实物管理并保留原号；有相关财务历史时先完成既有财务处置，再补登记归还依据。独立组件需先分别处理。

IA 的电子台账和 LS 的实物归还不等于新增无形资产摊销、租赁负债或支付计算；这些不在本次编码实现范围内。

批量建档可使用资产初始化 v4 Excel 模板，填写首次属性、取得年份及依据，组件填写已有正式主资产编号；v4 增加选填的设备编号。预览会检查编码资料，导入确认保存草稿，随后办理建档；不会预占号码或自动确认财务。v2、v3 旧文件继续按原列顺序兼容读取，统一编码必需而旧文件未提供的资料需用新版补齐。

## 数据与权限保护

- 沿用现有编码配置、资产实物维护、公司和部门范围权限；没有新增角色或自动扩大账号权限。
- 首次管理属性、编码年份、组件来源在发号后冻结。每次正式发号保存独立身份快照，技术更正追加新快照并保留原记录。
- 编号、组件、组合、来源和归还操作使用事务、幂等键及审计，关键关系和不可变历史同时由 PostgreSQL 约束保护。
- 已有旧规则编号保持原样，不从旧财务认定或文本编号中猜测并补写管理属性。新规则的号码与旧登记冲突时会拒绝重复发号。
- 新增记录已投入使用后，迁移会拒绝降回不能表示相应身份、电子确认、来源、组合或归还历史的旧结构，避免丢失数据。
- 日期控件使用浏览器要求的标准日期格式，避免中文本地化导致旧日期不显示。编号预览只发送必要编号参数，年份依据等自由文本在正式保存时提交。
