# 日常操作与界面改进

更新后，菜单中的“待确认折旧”统一显示为“财务确认”，原有单项和批量入口继续使用。菜单顶部可输入名称查找功能；在非输入状态下按 `/` 可定位全局资产搜索。

资产台账和财务待办可选择每页 25、50、100 或 200 条。长列表滚动时保留表头，分页可直接输入页码。选择上级部门时包含下属班组，资产台账的部门选项显示所属层级；所有筛选仍在原有公司、部门和人员权限范围内。

财务表单分为会计认定、折旧规则、期初余额、备注说明。与所选认定或折旧方式无关的字段自动收起；切换后再切回，尚未提交的输入值保留。保存会同时保留财务资料及折旧参数草稿，不生成已确认余额或折旧计划。确认后的资料继续使用原有调整流程。

未确认的会计认定改为受控非固定资产时，可撤除没有后续引用的折旧草稿，并保留操作记录。保存校验失败会整项回滚。手工折旧、工作量法的试算只展示参数和期初情况，后续按实际期间输入办理。

导入中心增加可分页的导入记录入口。资产导入明细默认显示资产名称、部门、责任人、位置、金额及校验情况，源表字段可展开查看。已导入批次显示当前建档和财务确认进度，提供下一步入口；原文件和历史导入明细保留。

临时编号明确标注为“草稿号”。表单前端校验未通过时不会锁住后续提交，调整选择后可继续办理。

本次不增加数据库结构或迁移。更新代码并重启应用后生效，已有资产编号、确认金额、折旧计划和审计记录保持原样。
