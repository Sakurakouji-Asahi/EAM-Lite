# 批量财务确认

在“报表与财务 → 财务确认”中选择资产，点击“核对所选资产”；也可以按导入批次、部门、资料状态或资产名称筛选后，点击“核对全部筛选结果”。每批最多 200 项，勾选可跨页保留。

核对页按每项已保存的资料展示会计认定、原值、期初累计折旧、减值、净值、残值、折旧方法、使用年限、起算日及实际接续日。合计仅包含本批可确认项目。缺少资料或校验不通过的项目显示具体原因和补充入口。

勾选已核对后，统一确认可办理项目。每项独立处理，失败项保留待办，页面逐项列出结果。预览后资产资料、金额或适用政策改变时，需要重新核对。批量操作沿用单项财务确认的权限、金额校验、折旧规则、审计和防重复提交机制。

已提足折旧的期初资产继续保持已提足状态，不新增未来折旧；未提足的按各自保存的实际接续日生成后续计划。财务确认本身不代替月度折旧批次的生成和确认，也不重新生成资产编号或二维码。

只有财务角色可以办理。批量建档结果提供前往财务待办的入口；单项财务确认入口继续保留。没有已保存财务资料的资产，应先补充资料；未完成实物建档的资产应先建档。

本功能不增加数据库表或迁移，更新代码并重启应用后生效。
