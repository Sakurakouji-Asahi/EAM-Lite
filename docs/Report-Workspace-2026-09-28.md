# 报表查询与汇总

更新：2026-09-28。

从“报表与财务 → 报表中心”进入。先选择逐件资产、财务与折旧、盘点保养清退、办公用品与低值品或 T+ 对账，再选择具体报表。

## 查询与查看

- 打开报表即可查看结果。月度计提和库存收发存默认查询本月；其他期间报表未填写日期时查询全部期间。
- 常用条件直接显示，责任人、资产状态等条件在“更多筛选”中。已填写的更多条件会自动展开。
- 资产关键词可查编号、名称、设备编号、型号等报表文本。数量物品可按部分编码或名称查询，也可用“物品编码（精确）”限定单一物品。
- 日期区间包含起止当天，可用“本月、上月、本年”填写，再点击“查询报表”。资产余额类报表按基准日查询；部门、责任人、位置和状态采用业务历史，其余档案信息采用当前资料。
- “重置条件”保留当前报表类型。每页可显示 25、50 或 100 条，分类汇总每页 20 组。
- 翻页保留已生效的日期和筛选条件；修改查询条件后保留每页条数。可输入页码直接跳转。
- 修改条件后，点击“查询报表”更新结果再导出；页面会提示尚未查询的修改。
- 资产总账按状态汇总，部门资产按部门汇总，人员资产按部门和责任人汇总。固定资产按会计类别汇总。
- 部门、人员和固定资产类别汇总中的记录数可点击进入对应明细；缺少归属档案或当前无权筛选该档案时不提供跳转。资产及折旧报表中的资产编号可打开当前资产档案，历史查询基准日不会改变当前档案。

## 财务口径

固定资产明细显示原值、实际累计折旧、减值准备和实际账面净值，净值等于原值减累计折旧及减值准备。折旧计划显示理论金额、计划状态及折旧版本，按状态分别汇总，历史替代计划不与现行计划合并；折旧明细显示已过账的累计折旧变动及来源。

月度计提分别列示：

| 栏目 | 含义 |
|---|---|
| 期初接续累计折旧 | 在该期间登记的期初累计折旧接续分录 |
| 本期计提 | 已确认批次的自动及手工计提原分录 |
| 折旧调整 | 折旧调整原分录 |
| 冲销净额 | 按冲销业务日期归属期间的反向分录 |
| 累计折旧变动净额 | 上述四项的代数和 |

期初接续不计入“本期计提”。已确认后发生冲销的原分录仍保留，冲销分录单独列示。月度报表的期间结束列为下一期间起点，不含当天；页面日期筛选仍包含结束当天。

## 数量、明细与导出

- 数量物品按单位分别汇总，单位成本、流水前后余额及明细中重复出现的原领用净余额不累加。
- 领用、退回和冲销分别汇总；不同处置状态的金额分别列示。
- 缺失金额保留空白并提示缺失数量，真实零显示为 0。金额按已有两位小数结果汇总，数量保留四位、单位成本保留六位。
- 页面金额采用千位分隔，费率按百分数显示；Excel 继续保存数值类型。
- “导出全部明细与汇总”导出当前筛选条件下的全部授权记录，包含明细和适用的分类汇总。翻页不限制导出范围；Excel 的分类汇总与明细来自同一遍数据读取。
- 查询和导出分别读取当时的数据；两次操作之间若有业务变更，结果可能变化，可按数据读取时间核对。
- T+ 对账的资产明细和实际折旧分录分别分页，文件仍按原对账格式导出。
- 财务金额和数量物品成本继续按岗位权限展示；无权查看的金额不进入页面汇总和导出汇总。
