# EAM-Lite

制造企业资产与低值物品管理工具，支持逐件资产、数量物品库存、领退与保管、盘点、保养、离职清退、折旧辅助核算及报表。当前版本 **0.3.0**。

## 在新电脑上开始使用

适用于 Windows 10/11。先安装并启动 Docker Desktop，使用 Linux 容器模式。首次启动需要联网获取镜像和依赖；不需要另行安装 Python、PostgreSQL、Git，也不需要手写配置文件。

1. 在本仓库选择 **Code → Download ZIP**，或从 [Releases](https://github.com/Sakurakouji-Asahi/EAM-Lite/releases) 下载 Windows 发行包。
2. 完整解压到任意普通文件夹；支持中文、空格和不同盘符。不要在压缩包预览窗口中直接启动。
3. 双击 **启动EAM-Lite.cmd**。程序检查运行环境、生成独立密钥、建立数据库、执行升级并启动服务。
4. 首次空库按提示设置管理员账号和密码，随后打开 **http://127.0.0.1:8765**，登录并完成公司及基础资料初始化。

程序随包提供前端资源。普通源码 ZIP 按内容校验标识构建；Windows 发行包优先使用固定摘要的镜像，镜像无法取得时使用经过校验的随包源码构建。

## 日常使用与迁移

- **启动EAM-Lite.cmd**：启动，已有同版本服务时直接打开。
- **停止EAM-Lite.cmd**：停止服务，保留数据和附件。
- **查看EAM-Lite状态.cmd**：查看运行状态与地址。
- **备份EAM-Lite数据.cmd**：生成加密的数据与附件备份。
- **恢复EAM-Lite数据.cmd**：在新电脑的空实例中恢复原账号、业务记录和附件。
- **更新EAM-Lite.cmd**：备份后更新到正式发行版本，拒绝自动降级。

GitHub 下载的是程序。已有业务数据通过加密 `.eambak` 备份迁移；不要复制数据库原始目录或把本机密钥放入仓库。更新前请保留独立备份。

完整步骤见 [Windows 本机使用说明](README-本机使用版.md)。本机默认仅监听 `127.0.0.1`；公司多终端使用按 [部署指南](docs/Sprint-12-Operations-Runbook.md) 配置独立的访问地址和 HTTPS。

## 主要功能

| 工作 | 功能 |
|---|---|
| 逐件资产 | 建档、编码、标签、调拨、借出归还、维修和处置 |
| 数量物品 | 库存、领退、调拨、保管、移动平均成本及盘点差异处理 |
| 财务辅助 | 财务确认、月度折旧、工作量集中录入、手工金额、理论试算和历史对照 |
| 日常待办 | 保养、问题跟进、借用归还、处置和离职清退 |
| 数据处理 | 标准模板导入、错误行下载、盘点表回传、报表筛选与完整导出 |
| 追溯与保护 | 来源单据跳转、操作日志、角色与部门范围、私有附件和加密备份 |

操作说明见 [财务与业务核对](docs/Business-Workspaces-2026-09-28.md)、[报表查询](docs/Report-Workspace-2026-09-28.md) 和 [低值物品操作](README-LOW-VALUE-GOODS.md)。折旧与成本沿用系统已配置口径；T+ 对账通过文件人工核对，不会自动写入 T+ 或生成正式会计凭证。
