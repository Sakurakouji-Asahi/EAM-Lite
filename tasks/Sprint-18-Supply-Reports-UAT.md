# Codex Task — Sprint 18：低值物品报表、Dashboard、核对与 UAT

## 前置

- Sprint 13–17 已验收。
- 基础档案、库存、保管、盘点和离职清退闭环可用。

本 Sprint 完成报表、导出、首页、余额重建工具、性能和业务 UAT。不要借此重新进行全仓库安全审计或无关重构。

## 目标

形成可正式使用的低值物品管理版本，并验证数量、金额、保管和逐件低值资产口径。

## 必须实现

### 1. 低值物品 Dashboard

至少显示：

- 物品档案数；
- 当前库存品种数；
- 库存数量和管理金额；
- 低库存品种数；
- 数量型耐用品在管数量和金额；
- 逐件受控非固定资产数量；
- 待过账单据；
- 未关闭盘点；
- 待处理离职保管项。

卡片与明细使用同一 QuerySet 和权限口径，可点击钻取。

### 2. 报表

实现并提供 Excel 导出：

1. 当前库存余额表。
2. 低库存预警表。
3. 库存收发存明细。
4. 库存流水表。
5. 领用明细表。
6. 部门领用汇总表。
7. 员工领用汇总表。
8. 数量型耐用品保管余额表。
9. 保管转交、归还、报损、报废明细。
10. 盘点差异与处理结果表。
11. 逐件受控非固定资产清单。
12. 低值物品综合管理金额表。

### 3. 报表口径

必须明确并测试：

```text
库存期末数量
= 期初 + 入库 + 退回 + 调入 + 盘盈
- 领用 - 调出 - 盘亏
```

金额同理按已过账流水。

耐用品：

```text
数量型耐用品公司在管金额
= 仓库库存金额 + 开放保管金额
```

逐件受控非固定资产原值单独列示，不与数量型金额相加为同一余额，除非报表清楚标注两套来源并分栏。

固定资产折旧、净值和 T+ 折旧导出不得包含 `controlled_non_fixed`。

### 4. Excel

- 使用 openpyxl 和项目现有导出规范。
- 数量、单价、金额为 Excel 数值。
- 日期为 Excel 日期。
- 大数据导出避免无界内存占用。
- 记录导出人、时间、类型、筛选条件和行数。
- 成本字段按权限隐藏或排除。

### 5. 余额核对和重建

完善命令：

```text
python manage.py reconcile_supply_balances --company <code>
python manage.py reconcile_supply_custodies --company <code>
python manage.py rebuild_supply_balances --company <code> --confirm
python manage.py rebuild_supply_custodies --company <code> --confirm
```

要求：

- reconcile 只读；
- rebuild 从不可变流水重建缓存；
- 默认 dry-run，没有 `--confirm` 不写入；
- 写入前输出差异摘要；
- 写入过程事务化并记录审计；
- 不删除或修改历史流水。

### 6. 导航和首页集成
